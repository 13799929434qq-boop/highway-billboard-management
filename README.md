# 高速公路广告牌管理系统

这是公路沿线广告牌经营管理项目。根目录只保存正式源码、正式文档和必要的项目配置；依赖、缓存、构建结果和临时工作副本均不作为项目文件保存。

## 目录说明

| 目录或文件 | 中文说明 | 使用方式 |
|---|---|---|
| `backend/` | 后端程序 | `app/` 保存正式代码，`tests/` 保存测试；`.venv/` 和测试缓存需要时重新生成 |
| `frontend/` | 前端程序 | `src/` 保存页面源码，`public/` 保存静态资源；`node_modules/` 和 `dist/` 需要时重新生成 |
| `docs/` | 正式项目文档 | 需求、设计、领域、架构、开发和项目管理资料统一放在这里 |
| `openspec/` | 已暂停的 OpenSpec 规格资料 | 当前不作为任务管理入口，保留现有配置和历史规格 |
| `.git/` | Git 版本历史 | 由 Git 自动管理，不要手动修改 |
| `.gitignore` | 不纳入 Git 的文件规则 | 排除依赖、缓存、构建产物、临时文件和本地配置 |
| `AGENTS.md` | AI 工作规则 | 供 Codex 等开发代理自动读取 |

`backend`、`frontend`、`src`、`app`、`tests`、`public` 等名称是开发工具使用的标准目录，因此保留英文，不另建重复的中文目录。

## 文件整理规则

- 同一份源码、文档、页面或交付物只保留一个现行版本。
- 不建立备份目录、历史归档目录或重复副本；旧版本统一通过 Git 历史恢复。
- 不把依赖、缓存、构建结果、截图、检查产物和临时脚本放入正式项目目录。
- 中文名称已经清楚的目录不额外增加索引；只有结构复杂且状态不易判断的目录才保留中文索引。
