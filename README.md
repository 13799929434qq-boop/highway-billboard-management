# 高速公路广告牌管理系统

公路沿线广告牌经营管理单位的业务系统：把路段、广告牌、客户、合同、收款、报表等业务全部线上化，替代 Excel + 纸质合同。

> 凡与本基线冲突的旧清单、旧交付件、旧设计，一律无效；它们已统一移入 [`archive/旧体系/`](archive/旧体系/) 留档，不得作为开发或验收依据。

## 开发批次

| 批次 | 内容 | 交付物 |
|---|---|---|
| 第一批（前置） | P1 登录 / 权限 / 数据字典 / 操作日志 | 能登录、能配权限、操作留痕 |
| 第一批（并行） | P6 报表界面（模拟数据） | 报表 / 筛选 / 导出可演示 |
| 第二批 | P2 广告牌建档 | 路段、广告牌、证件、照片 |
| 第三批 | P3 客户 + P4 合同 | 客户档案、多牌合同、年度价格 |
| 第四批 | P5 财务收钱核销 | 应收、收款、挂账、发票 |
| 第五批 | P8 售后 + P7 提醒 + 报表真实数据对接 | 售后闭环、提醒、数字对账 |

## 关键业务闭环（甲方验收场景）

录一块广告牌 → 签合同（多块牌、按年收钱）→ 收款核销 → 看报表，全部走通。
