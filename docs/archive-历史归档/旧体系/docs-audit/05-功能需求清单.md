## 当前不列入本期承诺的项目

客户门户、在线支付、外部财务系统对接、自动电子发票、原生手机 App、广告内容审核、完整会计核算：PRD/SRS 均列为 Won't/首期不做。此处只是现有方案的范围标注，最终仍以双方确认的需求基线为准。

## 使用前必须解决的优先级冲突

1. 原始要求报表可用并导出；Backlog 将经营报表和导出列为 Should，而 PRD 列核心报表 Must。
2. 原始将到期/欠费提醒列为可选；Backlog 将逾期预警列 Must，PRD 列提醒 Should。
3. PRD/SRS 将合同智能录入与风险摘要列 Must；Backlog 分别列 Should/Could，原始需求未提出 AI。
4. PRD 将合同变更、地图列 Should/Could；Backlog 将合同生效变更终止、地图点位列 Must/Should。
5. 原始对支出和报表有明确要求；PRD 将应付付款列 Should。须核对首期是否需要完整支出闭环。

本清单是需求盘点，不是批准后的开发任务列表。形成基线前，应给每条需求补客户决定、验收标准和 RTM 关联。
