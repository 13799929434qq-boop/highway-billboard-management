# 高速公路广告牌经营管理系统界面功能清单

版本：V1.0　状态：需求访谈整理稿，待甲方确认　整理日期：2026-09-21

## 1. 编制口径

本清单用于产品原型、页面设计和后续需求追踪。最高优先级来源为甲方原始文件 `output/docx/需求规格说明书_公路广告牌管理系统(2).pdf`；`output/docx/高速公路广告牌管理系统_需求调研报告_V1.0.docx` 和 `docs/audit/05-功能需求清单.md` 用于补充。原始 PDF 有明确要求时按其要求；未规定的流程按 `docs/audit/06-需求访谈决策记录.md` 中用户采纳的建议。后续 PRD/SRS/Backlog/原型文档只作为覆盖检查，不能提高或改变甲方原始需求的优先级。

**P0**：原始 PDF 明确要求的核心业务及跑通业务闭环所需界面；**P0-建议**：原始 PDF 留空、用户已采纳建议的控制流程；**P1**：调研报告或产品设计扩展，原始 PDF 未要求首期；**P2**：后续可选。P0-建议仍待甲方书面确认，P1/P2 不代表已获客户批准。

本清单以**整块广告牌**为合同关联和租期冲突单位：一份合同可关联多块牌，每块牌各年度价格可不同，同一块牌不得有租期重叠的两份生效合同。现有 PRD/SRS 中“广告面独立出租”的表述需在正式修订时统一；本清单不据此增加独立广告面签约界面。

## 2. 导航与全局入口

建议一级导航：经营首页、路段与广告牌、客户、合同、应收与资金、发票、经营报表、系统管理。P1/P2 模块根据获批范围显现。所有页面只展示当前用户有权访问的菜单与数据；直接访问地址仍须服务端鉴权。业务列表统一提供筛选、重置、分页、详情、在授权范围内导出和操作记录入口。金额显示币种与精度，日期显示时区/统计期间，敏感账号默认遮挡。

## 9. 每个页面必须覆盖的状态与规则

1. **共通状态**：加载中、空数据、筛选无结果、成功、字段校验失败、网络/服务错误、无权限、记录被他人改变。关键表单离开前提示未保存内容。
2. **业务确认**：合同确认、广告牌拆除/移位、黑名单、核销、付款、退款、作废等操作显示对象、金额或影响范围及确认人；成功后展示可追溯记录。防止重复提交。
3. **删除与历史**：原始 PDF 要求主要单据能删，但已被合同/账款引用的记录不能无痕物理删除；界面提供删除或作废入口，并在冲突时解释为何只能停用/作废。这一具体解释仍待甲方确认。
4. **权限**：菜单与按钮的隐藏只是体验；服务端仍逐次校验角色和数据范围。导出、附件、完整银行账号、敏感财务操作使用独立权限。任何报表汇总不得包含用户无权查看的数据。
5. **金额一致性**：应收账单、收款流水、核销、客户挂账、应付、付款和发票各自保留独立记录；列表、详情、报表和导出必须使用相同统计口径，并能下钻到来源。
6. **合规**：三个桩号分别录入，不合并；路政、保险、年审有效期清晰显示；用地性质导致的经营限制在广告牌详情和合同提交时同步提示。

## 10. 甲方确认前的界面验收检查

- 原始 PDF 的全部明确要求均有入口：路段/广告牌/商家档案、字典、合同、多牌多年计价、资金收支、四张报表、筛选与 Excel 导出、权限、审计、合规资料。
- 能从建档一块广告牌开始，完成客户建档、签订多牌合同、生成按年应收、登记部分收款并核销、在四张报表中看到一致结果。
- 首期 P0 页面无“假数字”、无只在前端生效的权限、无覆盖正式合同和资金历史的编辑操作。
- P0-建议、P1、P2 在原型和任务计划中显著标明来源及确认状态；甲方未确认前，不宣称正式验收范围已冻结。
