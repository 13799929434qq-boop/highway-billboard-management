# 项目文档总目录

本目录是高速公路广告牌管理系统的统一文档库。文件夹采用“英文技术名-中文标识”命名，既保留工程工具兼容性，也便于中文检索。

## 状态标识

| 标识 | 含义 |
|---|---|
| **现行基线** | 当前规划、开发和验收必须遵循 |
| **现行规则** | 当前有效的领域、架构或协作约束 |
| **待批准** | 内容已形成，但尚需负责人或甲方确认 |
| **设计中** | 仍在评审或迭代，不应视为最终验收基准 |
| **参考资料** | 可辅助开发，不是需求或验收依据 |
| **历史归档** | 仅用于追溯，不得覆盖现行基线 |

## 推荐阅读顺序

1. [`overview-项目说明/项目说明.md`](overview-项目说明/项目说明.md)：了解项目目标、基线和开发批次。
2. [`requirements-需求文档/需求基线_TAPD对齐版_V1.0.md`](requirements-需求文档/需求基线_TAPD对齐版_V1.0.md)：确认范围、优先级和 TAPD 需求。
3. [`domain-领域模型/CONTEXT-领域上下文.md`](domain-领域模型/CONTEXT-领域上下文.md)：统一领域术语和业务口径。
4. [`adr-架构决策/架构决策总表-现行规则.md`](adr-架构决策/架构决策总表-现行规则.md)：读取当前有效的架构决策。
5. 按任务进入技术架构、产品设计或开发文档目录。

## 目录边界

- 根目录 `README.md` 只保留最短文档入口，完整项目说明位于 `overview-项目说明/`。
- 根目录 `AGENTS.md` 是开发代理自动发现的控制文件，必须保留原位；其用途说明纳入项目管理分类。
- 根目录 `openspec/` 是已暂停的工具配置与历史变更，保留原位，不属于当前任务管理流程。
- `.agents/` 是代理技能配置，不是项目业务文档。
- `.artifact-work/` 是 Git 忽略的临时工作副本，不能作为正式文档来源。
- `frontend/`、`backend/` 内的依赖、缓存和配置文件不属于项目文档库。
