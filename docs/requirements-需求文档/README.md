# 需求文档说明

## 使用顺序

1. 开发、设计和验收首先读取 [`需求基线_TAPD对齐版_V1.0.md`](需求基线_TAPD对齐版_V1.0.md)。
2. 需要核对需求来源时，再查看 TAPD 附件和甲方原始资料。
3. 原始资料或附件与现行基线不一致时，不自行选择版本，应以 TAPD 已确认内容和双方确认记录为准。

## 现行基线

- [`需求基线_TAPD对齐版_V1.0.md`](需求基线_TAPD对齐版_V1.0.md)：产品范围、页面分组、功能点、优先级、TAPD ID 和开发批次的唯一有效本地基线。

| [`需求规格说明书-甲方原始版.pdf`](source-原始资料/需求规格说明书-甲方原始版.pdf) | 甲方需求规格来源 | 原始资料 |

## TAPD 附件

[`tapd-attachments-TAPD附件/`](tapd-attachments-TAPD附件/) 保存 TAPD 中的敏捷需求 Word 附件，并按需求基线的页面编号分组：

| 文件夹 | 内容 |
|---|---|
| `P0-全局与工作台` | 经营工作台及结构化内容 |
| `P1-账号与系统管理` | 登录、权限、字典和操作日志 |
| `P2-广告牌资产管理` | 路段、广告牌档案、证件、照片和资产变动 |
| `P3-客户管理` | 客户档案、开票、余额、黑名单和客户业务查询 |
| `P4-合同管理` | 合同新建、多广告牌、年度价格、状态、变更和附件 |
| `P5-财务管理` | 应收、收款、挂账、核销、支出和发票登记 |
| `P6-经营统计报表` | 数量、合同、收款、欠款、收益和报表导出 |
| `P7-消息与到期提醒` | 合同、欠费、证件和付款提醒 |
| `P8-售后维护管理` | 售后登记、处理进度和维修记录 |

## 整理规则

- TAPD 附件只保留一套可直接查看的文件，不重复保存压缩包和二次解压副本。
- 原始资料保留来源和版本含义，不把历史调研报告误认为现行需求。
- 需求基线内容发生变化时，必须有对应的 TAPD 或双方确认依据。
