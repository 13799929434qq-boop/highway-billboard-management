### P0 全局与工作台　【High】

#### 01 经营工作台（登录首页）
`TAPD ID 1164099159001000189`　页面编号：H-01　优先级：High

**【用户故事（User Story）】**
作为 系统用户（运营档案员、合同管理员、财务管理员、售后维护人员、部门领导、系统管理员），
我希望 登录后默认进入经营工作台，看到与本人角色和数据权限匹配的待办提醒、核心指标和常用入口，
以便 快速掌握经营概况并直达待处理业务，无需逐个菜单查找。
**【验收标准】**
• 登录后默认进入经营工作台。
• 根据当前用户的角色和数据权限展示内容。
• 展示待办提醒、核心指标和常用入口。
• 点击指标或提醒进入已有业务页面。
• 无权限内容不显示。
• 加载失败必须显示错误状态，不能显示为零。
• 工作台只汇总已有业务，不引入新的审批或业务状态。
• 首期不支持拖拽布局、自定义组件或复杂经营大屏。

### P1 账号与系统管理　【High】

#### 01 账号密码登录
`TAPD ID 1164099159001000187`　优先级：High（随页面）

**【用户故事（User Story）】**
作为 系统用户（运营档案员、合同管理员、财务管理员、售后维护人员、部门领导、系统管理员），
我希望 可以输入账号密码完成系统登录，
以便 进入系统使用广告牌管理、合同管理等相关业务功能。
**【验收标准】**
• 输入正确用户名密码，可以成功登录，进入系统首页。
• 用户名或者密码输入错误，给出明确提示，不进入系统。
• 未登录直接访问业务 URL，自动跳转登录页面。
• 点击退出登录，会话失效，跳转登录页，回退无法回到业务页面。
• 密码连续输错 5 次账号被锁定，锁定账号无法登录。
• 禁用账号无法登录。
• 登录会话超时（30 分钟）后，操作页面会跳转登录页，需要重新输入账号密码。

#### 02 岗位权限设置
`TAPD ID 1164099159001000186`　优先级：High（随页面）

**【用户故事（User Story）】**
作为 系统管理员，
我希望 可以为不同岗位配置菜单、数据和按钮权限，
以便 各岗位人员只能访问其职责范围内的系统功能和业务数据。
**【验收标准】**
• 系统管理员可以新增岗位并为其配置菜单、数据和按钮权限，保存后配置生效。
• 为岗位分配菜单后，该岗位用户登录后仅可见已分配菜单，未分配菜单不显示。
• 数据权限设置为本人数据时，该岗位用户列表中仅显示本人创建或负责的数据。
• 按钮权限取消导出后，该岗位用户页面中导出按钮不可见或不可点击。
• 将用户从岗位移除后，该用户重新登录后失去对应岗位权限。
• 禁用岗位后，归属该岗位的用户无法使用该岗位对应的功能。
• 系统管理员岗位无法被禁用或删除。
• 所有权限变更操作均有日志可查。

#### 03 不同岗位看到的内容不一样
`TAPD ID 1164099159001000185`　优先级：High（随页面）

**【用户故事（User Story）】**
作为 六类岗位的业务人员，
我希望 登录系统后只看到与本人岗位职责相关的菜单、数据和操作按钮，
以便 在不被无关信息干扰的前提下完成本职工作，并避免越权访问敏感业务数据。
**【验收标准】**
• 六类岗位分别登录后，左侧菜单与各自职责范围一致。
• 运营档案员登录后看不到财务收款流水等财务模块。
• 财务管理员登录后看不到广告牌档案的新增编辑按钮。
• 部门领导登录后仅见报表和查询菜单，无业务单据新增入口。
• 通过URL直接访问未授权菜单时，系统拒绝并提示无权限。
• 多岗位用户登录后可见菜单为各岗位菜单的并集。

**【用户故事（User Story）】**

• 历史单据中已选的停用选项仍能正确显示原选项名称。
• 对已被引用的选项执行删除时系统拒绝并提示。
• 字典维护操作在操作日志中可查。

#### 05 操作留痕查询
`TAPD ID 1164099159001000183`　优先级：High（随页面）

**【用户故事（User Story）】**
作为 系统管理员，
我希望 对关键业务操作保留操作日志并支持按条件查询，
以便 在出现数据争议或错误时追溯操作人、时间和变更内容。
**【验收标准】**
• 对广告牌档案执行修改后，操作日志中可查到操作人、时间和变更前后内容。
• 按操作人加时间范围查询，可列出该用户在该时段的全部关键操作。
• 打开某块广告牌档案，可查询到该档案的全部操作历史。
• 删除操作时弹出二次确认，确认后日志中留有删除记录。
• 普通业务用户无法在界面上修改或删除操作日志。
• 越权查询他人敏感操作日志时被拒绝。

• 广告牌档案登记时，所属路段、地区、运营单位下拉框来源于本功能维护的数据。
• 可按路段名称或运营单位查询出对应路段档案。

• 可对已有广告牌基本信息进行编辑并保存。

#### 03 记三个桩号
`TAPD ID 1164099159001000180`　优先级：Middle（随页面）

**【用户故事（User Story）】**
作为 运营档案员，
我希望 在广告牌档案中分别记录合同桩号、现场桩号和路政批复桩号，

• 档案详情中可同时看到三个桩号的值。
• 三个桩号均未填写时不允许保存档案。
• 桩号修改后操作日志中留有记录。

#### 04 登记证件有效期
`TAPD ID 1164099159001000179`　优先级：Middle（随页面）

**【用户故事（User Story）】**
作为 运营档案员，
我希望 按路政审批、保险、年审分别登记证件编号和有效期，
以便 系统据此提醒证件到期，避免广告牌因手续过期产生合规风险。
**【验收标准】**

• 每条手续记录可录入证件编号、办理日期、生效日期、到期日期和附件。
• 到期日期已过的手续在台账中标记为已过期。
• 临近到期的手续在台账中高亮或提醒。
• 可按手续类型或到期状态筛选出对应手续列表。
• 无路政审批手续的公路用地广告牌给出违规风险提示。

**【用户故事（User Story）】**

• 已关闭问题单不能重新打开，部门领导不能修改问题状态。
