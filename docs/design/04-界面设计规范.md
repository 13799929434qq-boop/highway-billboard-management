# 高速公路广告牌管理系统｜界面设计规范 V1.0

状态：现行 UX 与后续 UI 的统一执行标准  
适用范围：现行 PRD 的 P1～P8 页面  
产品类型：桌面端企业经营管理后台  
基准视口：1440×900；最低支持宽度：1024px

## 1. 设计原则

1. **业务优先**：页面首先帮助用户查找、核对、录入和追溯，不用装饰性大卡片占据空间。
2. **统一骨架**：六类岗位共用同一套页面骨架，通过权限决定菜单、数据和按钮。
3. **适度密度**：采用中等密度，表格可连续浏览，表单仍保留清晰分组。
4. **少量圆角**：圆角表达组件层级，不能每个元素都使用不同半径。
5. **状态可读**：状态必须有文字，不能只用颜色表达。
6. **异常可恢复**：错误必须说明原因、是否保留数据以及下一步操作。

## 2. 基础设计变量

### 2.1 间距

以 **4px** 为最小单位，常用间距为：

| Token | 数值 | 用途 |
| --- | ---: | --- |
| space-1 | 4px | 图标与短文本、紧凑内部间距 |
| space-2 | 8px | 同组按钮、字段提示、表格操作 |
| space-3 | 12px | 筛选控件、紧凑卡片内部 |
| space-4 | 16px | 表单字段、内容面板内部 |
| space-6 | 24px | 页面内主要区块、页面左右留白 |
| space-8 | 32px | 大区块之间 |

禁止出现没有理由的 7px、13px、17px 等零散间距。

### 2.2 圆角

| Token | 数值 | 用途 |
| --- | ---: | --- |
| radius-sm | 4px | 小型标签、分段控件内部 |
| radius-md | 6px | 按钮、输入框、下拉框、菜单项 |
| radius-lg | 8px | 筛选容器、表格外框、表单分组、弹窗 |
| radius-pill | 999px | 状态标签、筛选标签、头像 |

规则：

- 同一种组件只能使用同一种圆角。
- 普通卡片不得使用 16px 以上的大圆角。
- 抽屉贴右侧屏幕边缘，不设置外侧圆角。
- 全圆角只能用于短标签、状态和头像，不用于普通按钮。

### 2.3 控件高度

| 尺寸 | 高度 | 用途 |
| --- | ---: | --- |
| Small | 24px | 表格内极紧凑操作、微型分页 |
| Default | 32px | 普通按钮、输入框、下拉框、分页 |
| Large | 40px | 登录页、关键提交操作 |

同一工具栏内的按钮、输入框和下拉框必须等高。

### 2.4 字体

字体族：`Microsoft YaHei`, `PingFang SC`, `Noto Sans SC`, sans-serif。

| 层级 | 字号/行高 | 字重 | 用途 |
| --- | --- | ---: | --- |
| 页面标题 | 22/30px | 600 | 每页唯一主标题 |
| 区块标题 | 16/24px | 600 | 表单分组、详情分组 |
| 正文 | 14/22px | 400 | 表单、详情、表格正文 |
| 辅助信息 | 12/20px | 400 | 提示、元信息、面包屑 |
| 数据强调 | 20/28px | 600 | 报表关键数字，谨慎使用 |

正文不得小于 12px；表格正文采用 14px，低保真图缩放展示时除外。

## 3. 色彩

### 3.1 中性色

| 用途 | 色值 |
| --- | --- |
| 主文字 | `#1F2329` |
| 次文字 | `#646A73` |
| 禁用文字 | `#A2A7AE` |
| 页面背景 | `#F5F6F7` |
| 容器背景 | `#FFFFFF` |
| 表头/次级背景 | `#F2F3F5` |
| 默认边框 | `#D9DDE2` |
| 强边框 | `#B8BEC6` |

### 3.2 功能色

| 状态 | 色值 | 使用规则 |
| --- | --- | --- |
| 主操作 | `#315E8A` | 主按钮、选中状态、链接 |
| 成功 | `#2F7A52` | 保存成功、有效、完成 |
| 警告 | `#A66A18` | 临期、风险、待处理 |
| 错误 | `#B0443E` | 失败、过期、字段错误 |
| 信息 | `#526D82` | 普通说明、处理中 |

每个状态同时使用文字；颜色只是辅助。

## 4. 页面骨架

```text
┌────────────────────────────────────────────────────────────┐
│ 顶栏 56px：面包屑                         用户与退出       │
├─────────────┬──────────────────────────────────────────────┤
│ 左侧导航     │ 页面标题                         主操作      │
│ 208px       │ 页面说明                                      │
│             │                                                │
│ 当前模块     │ 筛选区 / 摘要                                 │
│             │                                                │
│             │ 列表、详情、表单或报表                         │
│             │                                                │
└─────────────┴──────────────────────────────────────────────┘
```

- 左侧导航：208px，可在后续实现中收起；当前菜单必须突出。
- 顶栏：56px，不放无业务价值的装饰。
- 页面内边距：24px。
- 页面标题区与主体间距：24px。
- 页面同一层级最多一个主按钮。
- 当前阶段不设置独立工作台，登录后进入岗位主要页面。

## 5. 按钮

### 层级

1. **主按钮**：页面最重要动作，例如“新建广告牌”“保存合同”。同一操作区最多一个。
2. **次按钮**：导出、取消、返回、重置。
3. **文字按钮**：表格中的查看、编辑。
4. **危险按钮**：解除、作废等需要明确后果的动作。

按钮文案使用“动作 + 对象”，例如“保存档案”“确认核销”，不使用含糊的“确定”“提交”。

## 6. 表格与筛选

- 筛选区使用 8px 圆角容器，内部控件高度统一为 32px。
- 常用条件直接展示，更多条件再展开；现行功能没有定义高级筛选时不添加。
- 已生效筛选条件应可识别，查询和导出必须使用同一条件。
- 表头高度 40px，普通单行表格行高 48px。
- 两行信息时行高 64px。
- 表格列顺序：识别信息 → 业务信息 → 状态 → 时间 → 操作。
- 行内操作最多直接显示两个，其余操作放入更多菜单；现行页面操作不超过两个时直接显示。
- 分页高度 32px，与默认控件一致。
- 空数据、筛选无结果和无权限必须使用不同状态。

## 7. 表单

- 标签始终显示，不能只使用占位符。
- 一行最多两个普通字段；长文本、附件和复杂明细独占一行。
- 必填标识放在标签处。
- 帮助文字放在字段下方。
- 校验失败时同时显示字段错误与页面错误摘要；已填写内容不清空。
- 多步骤表单只用于合同、复杂档案等确实存在顺序的业务。
- 取消或离开包含未保存修改的页面时需要提示。

## 8. 详情与快速详情

- 快速详情宽度建议 400～480px，只展示识别信息、关键状态和主要动作。
- 完整资料、附件、历史和复杂明细进入正式详情页。
- 详情页使用页签时，页签按照业务理解排列，不按数据库表排列。
- 关闭快速详情后保留原筛选、分页和滚动位置。

## 9. 状态与反馈

每个核心页面至少考虑：

1. 加载中：保留页面结构，避免闪烁。
2. 首次无数据：解释用途，并在有权限时提供新建入口。
3. 筛选无结果：提供清除筛选。
4. 保存中：主按钮进入加载状态并防止重复提交。
5. 保存成功：说明保存对象，并提供查看或返回动作。
6. 保存失败：说明是否保留内容，并提供重新保存。
7. 无权限：说明无权访问，返回有权访问的页面。

## 10. 权限表现

- 没有菜单权限：菜单不显示。
- 没有按钮权限：按钮不显示或禁用，按照需求基线执行。
- 没有数据权限：数据不出现在列表中。
- 直接访问未授权 URL：显示无权限页面，不能伪装成空数据。
- 系统管理员不自动获得业务数据查看权。

## 11. 适用组件映射

| 页面类型 | 统一结构 |
| --- | --- |
| 登录页 | 独立全屏、Large 控件、单一登录动作 |
| 列表页 | 标题与主操作 → 筛选 → 结果数量 → 表格 → 分页 |
| 详情页 | 标题与状态 → 关键动作 → 页签/分组 → 历史 |
| 表单页 | 标题 → 步骤（必要时）→ 分组字段 → 固定操作区 |
| 报表页 | 标题与导出 → 筛选 → 指标/图表 → 明细表 |
| 提醒页 | 类型页签 → 筛选 → 提醒列表 → 处理结果 |

## 12. 参考依据

- Ant Design Design Tokens：基础圆角 6px，大圆角 8px，默认控件高度 32px。
- Carbon Design System Data Table：中型表格行高 40px、大型行高 48px，表格与分页保持尺寸一致。
- 本项目 `CONTEXT.md`、现行需求基线及 ADR-0003、ADR-0005。

本规范只定义现有页面如何保持一致，不增加任何业务功能。
