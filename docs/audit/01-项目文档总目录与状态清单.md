## 重复与辅助材料

- `.docx-qa`、`.docx-qa-v2` 中的 PDF/PNG 是 `deliverables/01` 至 `05` 的渲染检查副本；`tmp` 下 PDF/PNG/文本是调研、需求及设计文档的生成和 QA 过程材料，不作为新增正式文档。
- `.xlsx-qa` 是工作簿截图；`deliverables/*.xlsx.inspect.ndjson` 是检查输出；`docs/architecture/*.visual-check.*` 是架构图可视化检查文件。
- 未在项目目录发现 `docs.rar` 或其他压缩包，故无法核对其内部文件或与单独上传文件的重复关系。未发现 Figma/MasterGo/Axure 等原型源文件。
- 文件名中的 V1.0 只表示版本标签。PRD 等文内明确为“待客户评审”或“待客户确认”，不能列为“已确认”。

## 引用链现状

原始 PDF → 调研报告 → PRD/SRS → 产品/业务/技术设计 → Backlog → 测试方案的文件链可识别，但没有稳定的需求编号、双向 RTM、批准记录和变更记录；因此现阶段只能做主题级追溯，不能证明每条需求均已覆盖或获批。
