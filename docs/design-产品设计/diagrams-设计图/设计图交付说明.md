# 设计图交付说明

本目录保存当前信息架构图和核心业务流程图。HTML 用于直接查看，JSON 是对应的可编辑源文件。

## 文件对应关系

| 图稿 | 查看文件 | 源文件 | 用途 |
|---|---|---|---|
| 信息架构 | [信息架构.html](信息架构.html) | [信息架构源文件.json](信息架构源文件.json) | 展示登录授权、导航与业务模块关系 |
| 核心业务流程 | [核心业务流程.html](核心业务流程.html) | [核心业务流程源文件.json](核心业务流程源文件.json) | 展示建档、合同、应收、收款、核销与报表的主流程 |

## 使用边界

- 图稿是产品设计说明，不替代需求基线、领域规则或架构决策。
- 需求范围以 `docs/requirements-需求文档/需求基线_TAPD对齐版_V1.0.md` 为准。
- 业务术语以 `docs/domain-领域模型/CONTEXT-领域上下文.md` 为准。
- 图中未表达的异常流程、权限细节和金额规则，不得根据图形自行推断。

## 维护规则

- 修改图稿时同步更新对应 HTML 和 JSON 源文件。
- 每类图只保留一个现行版本；旧版本从 Git 历史恢复。
- 不在本目录保存截图、浏览器校验回执、生成缓存或临时文件。
- 更新后同步维护上级目录的 [产品设计中文索引](../00-中文索引.md)。
