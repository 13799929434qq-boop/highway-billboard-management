# 产品设计中文索引

本目录只保留现行设计文档、当前高保真页面、正式设计图，以及需要长期保留的参考和决策记录。同一个业务页面只保留一个现行版本，旧页面、对比稿、截图和生成缓存通过 Git 历史追溯。

## 当前结论

- 当前设计方式：直接制作高保真可点击页面，不再维护低保真线框。
- 广告牌资产页面：采用“档案索引册”视觉方向和三栏档案索引工作台布局。
- 需求范围仍以 [`需求基线_TAPD对齐版_V1.0.md`](../requirements-需求文档/需求基线_TAPD对齐版_V1.0.md) 为准。

## 整理规则

- 同一个业务页面只保留一个标记为“现行版”的文件。
- 不保存同一页面的 A/B/C 候选、旧版本截图、自动校验图片、缓存或临时生成脚本。
- 旧版本和探索过程统一从 Git 历史恢复。
- 参考材料不得覆盖现行设计文档和需求基线。
