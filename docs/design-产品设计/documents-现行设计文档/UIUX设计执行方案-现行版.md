## 二、确定执行方案（五步，工具×产物×闸门）

| 步骤 | 名称 | 工具 | 产物 | 闸门 |
|---|---|---|---|---|
| **S1** | UX 与信息架构 | Mermaid + Markdown | 信息架构、用户流程、MVP 页面清单 | 审核 |
| **S2** | 布局与高保真方向 | HTML + 视觉规范 | 使用真实设计变量制作高保真布局方向，不再交付低保真线框 | 选定布局 |
| **S3** | 视觉风格 + 设计系统 | Seedream + 继承旧 DESIGN.md | 风格对比（旧暖色风 + 1 备选）、04-设计系统(Token/组件)、更新 DESIGN.md | 选定风格 |
| **S4** | 高保真可点击原型 | HTML + ECharts | 全 MVP 高保真、4 报表图表、加载/空/错全状态、可点击走查；05-交互说明、06-UX验收清单 | UX 走查 |
| **S5** | 设计交付与开发衔接 | Markdown + 部署 | 07-页面↔TAPD 映射、08-前端交付清单、Vercel 原型链接、UI/UX 验收报告 | 阶段验收 |

**排期（建议工作量）**：S1 约 1 天、S2 与 S3 合计约 3–4 天、S4 约 3–4 天、S5 约 1 天；每步必须经审核才进入下一步，不连续自动执行。
