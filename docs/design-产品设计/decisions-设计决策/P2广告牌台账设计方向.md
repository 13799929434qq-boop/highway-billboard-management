# P2 广告牌台账设计方向

## 共同任务

运营档案员在桌面端查找广告牌，核对路段、现场桩号、经营状态与手续状态，并进入正式档案。三版使用相同功能和相同数据，不增加需求基线以外的能力。

## A 路段作业台

- 北极星：像在运营中心边查台账边核对现场资料。
- 调性：安静、精致、中高密度、中等分量、庄重。
- 骨架：业务导航、台账、选中记录摘要三栏并列，首屏同时完成查找与核对。
- 字体：无衬线中文，名称和操作加粗，数据保持紧凑。
- 色彩：道路深灰 `#172630`、路牌蓝 `#255F7F`、施工橙 `#E36D2F`。
- 记忆点：选择表格行后，右侧固定显示三个桩号和手续摘要。
- 放弃：大面积留白、统计卡片、装饰图标。

## B 档案索引册

- 北极星：像查阅一套管理严谨的正式资产档案。
- 调性：安静、精致、中等密度、较轻、庄重。
- 骨架：顶部业务目录、左侧路段索引、右侧横向档案条目。
- 字体：中文宋体负责标题与名称，无衬线负责控件和说明，编号与桩号使用衬线数字。
- 色彩：档案纸 `#F6F3EB`、印章红 `#8F3029`、墨灰 `#282A28`。
- 记忆点：广告牌记录以“档案条目”呈现，编号和桩号拥有更强辨识度。
- 放弃：传统深色侧栏、普通数据表格外观、蓝色企业后台默认风格。

## C 公路调度板

- 北极星：像在路网调度席位上快速扫过每块广告牌的经营和合规信号。
- 调性：中等能量、精致、高密度、较重、庄重。
- 骨架：取消左侧业务栏，顶部业务导航与路段带固定，台账横向铺满。
- 字体：窄感无衬线与醒目数字，强调横向扫描。
- 色彩：调度深绿 `#10282A`、运行绿 `#176B67`、道路标线黄 `#D6B52A`。
- 记忆点：经营状态使用短横状态量，手续风险使用道路标线黄提示。
- 放弃：卡片、抽屉、分散操作和传统“左侧栏 + 内容卡片”骨架。
