## 二、V1.1 → V1.2（6 项，条件通过小修）

| # | 位置 | V1.1 问题 | V1.2 修订 |
|---|---|---|---|
| 13 | B6/第七章 | Alembic 初始化前置与边界不清 | 明确前置依赖（装 alembic 带入 SQLAlchemy）；阶段一**仅初始化迁移环境，不执行迁移/不建业务表** |
| 14 | B7/F5 | 可能预建空目录 | **只创建当前实际使用目录**，不预建空目录/占位文件 |
| 15 | F1/技术栈 | 安装与类型检查口径不明 | 锁存在时用 **`pnpm install --frozen-lockfile`**，禁止擅自升级；明确类型检查 **`pnpm exec vue-tsc -b`** |
| 16 | API 错误码 | 401x/403x/422x 易被当成已定码 | 明确**现阶段仅为错误码类别**，阶段二固化最小错误码表 |
| 17 | 认证/部署/阶段二 | 跨站 Cookie 关系未验证 | 列为**阶段二必须验证**：跨站部署、SameSite、CSRF、正式域名关系 |
| 18 | 待确认事项 | 缺少确认记录机制 | 增**确认人/确认日期/最终结论/关联 TAPD**；**拟定默认值不自动成为正式需求** |

## 三、执行边界

- V1.1、V1.2 两轮均**仅修订文档**：未改业务代码、未装依赖、未迁移、未创建工程设施、未扩展新架构能力。
- V1.0、V1.1 原文保留作为历史版本；V1.2 为待批准的阶段一基线。
