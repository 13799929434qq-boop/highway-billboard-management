## Why

系统目前尚无可运行的身份入口，六类内部用户无法安全进入后续业务模块。账号密码登录是第一批前置能力，也是菜单权限、数据权限和操作留痕生效的基础。

## What Changes

- 提供账号密码登录与明确的失败反馈，成功后进入系统首页。
- 对未登录访问业务 URL 的请求进行拦截并跳转登录页。
- 提供退出登录并立即使会话失效，防止通过浏览器回退恢复业务页面。
- 对连续 5 次密码错误的账号执行锁定，并拒绝已锁定或已禁用账号登录。
- 将登录会话的无操作超时设为 30 分钟，超时后要求重新登录。
- 为前端路由保护与后端业务 API 建立一致的认证边界。

## Capabilities

### New Capabilities

- `identity/account-password-authentication`: 定义内部用户的账号密码认证、失败锁定、禁用校验、会话超时、退出和未认证访问保护。

### Modified Capabilities

无。

## Impact

- 新增 Vue 3 管理端登录页、认证状态管理、路由守卫和退出入口。
- 新增 FastAPI 认证接口、受保护接口依赖以及账号和会话相关持久化模型。
- MySQL 保存账号状态与认证安全事实；Redis 可用于会话和失败计数，但不得成为账号状态的唯一事实来源。
- 后续岗位权限和操作日志能力将复用当前认证主体与会话边界，但不包含在本次变更范围内。
