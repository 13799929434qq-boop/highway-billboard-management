# Project agent instructions

The project already has `openspec/config.yaml`. Preserve its configuration and artifacts; do not initialize OpenSpec again. Read `CONTEXT.md` and relevant `docs/adr/` decisions before changing domain behavior.

## Agent skills

### Issue tracker

Project work is tracked in GitHub Issues after the GitHub remote is connected. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout: root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
